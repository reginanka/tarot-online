# 🔮 Online Tarot Reading Application

A modern, responsive, and bilingual (Ukrainian & English) single-page application for professional Tarot readings.

---
### 🇺🇦 Коротко про проект
Це сучасний веб-додаток для онлайн-гадання на картах Таро. Містить 28 професійних розкладів, повну колоду з 78 карт та інтеграцію з ШІ для глибокого тлумачення результатів. Проект розроблений під брендом **Gearberry**.
---

## ✨ Key Features

- **28 Professional Layouts**: Ranging from simple 1-card draws to complex 21-card spreads (Celtic Cross, Tree of Life, etc.).
- **Full 78-Card Deck**: Includes both Major and Minor Arcana with high-quality localized interpretations.
- **Bilingual Support**: Full localization for Ukrainian and English languages.
- **Privacy Oriented**: No data collection or backend required. All readings are processed locally in the user's browser.

## 🤖 AI Tarot Specialist: Gemini Bot

This project is uniquely integrated with a custom-trained **Gemini Bot** (internally known as **Leia**) to provide deep, contextualized interpretations of your readings.

- **No Limits**: Specifically designed to be accessible to everyone without typical AI usage limits.
- **Specially Trained**: Unlike general-purpose AI, this bot is fine-tuned to understand Tarot symbolism, esoteric meanings, and the specific positions of our 28 layouts.
- **Seamless Flow**: The app allows you to copy your reading with one click and instantly jump to the bot for a detailed conversation about your cards.

👉 **[Try the Gemini Tarot Bot Here](https://surl.lt/ygtinw)**

## 🛠️ Tech Stack

- **HTML5**: For semantic structure.
- **JavaScript (Vue.js 3)**: Framework used for state management and UI reactivity.
- **Tailwind CSS**: For high-end styling and responsive layout.
- **Font Awesome 6.5.1**: For high-quality iconography (including social media).
- **Google Fonts**: "Cormorant Garamond" for that elegant, esoteric feel.

## 🚀 How to Run

Since this is a static single-page application (SPA), there is no installation or build step needed.

1. Clone the repository.
2. Open `index.html` in any modern web browser.
